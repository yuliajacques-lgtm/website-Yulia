PUBLIER SUR GITHUB PAGES
1. Décompresser cette archive.
2. Remplacer les fichiers de la racine publiée : index.html, coaching.html,
   about.html, contact.html, tarifs.html, site.js, styles.css, et assets/.
3. Conserver votre fichier CNAME, votre configuration GitHub Pages et tout
   fichier .nojekyll existant.
4. Vérifier que la publication GitHub Pages est terminée, puis rafraîchir le site
   avec Cmd + Shift + R (Mac).
